# LNKTA Async Popup

Open saved Elementor templates in an async WordPress popup. Use the Full screen control to expand or restore an open popup.

Install the plugin ZIP from the latest stable release. WordPress checks future releases for updates. Enable auto-updates for LNKTA Async Popup on the Plugins screen to install them automatically.

The source is in `async-template-menu/`. Each stable `vMAJOR.MINOR.PATCH` tag contains its installable ZIP at `dist/async-template-menu.zip`.
